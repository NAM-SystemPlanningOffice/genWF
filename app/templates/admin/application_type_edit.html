基本情報

一意の識別コード（例: ACC001）
表示用の名前（例: アカウント管理）
開発中の申請種類は管理者のみ表示され、一般ユーザーは申請を提出できません

対応する操作（アクションタイプ）

複数レコード入力の場合、1回の申請で複数の追加・修正・削除を行います（例: メンバー管理）
・候補選択: is_member='N'のレコードから選択して追加（例: メンバー管理、権限付与）
・自由入力: 空のフォームを追加して自由に入力（例: 経費明細、契約条項）
単一レコードの場合、各アクションタイプごとに個別の申請を行います

申請対象設定

・任意: すべてのユーザーが申請可能
・特定所属のみ: 下記で指定した所属コードのみ申請可能
・特定ユーザーのみ: 下記で指定したユーザーIDのみ申請可能
※所管所属による制限は「親リソース検索クエリ」で :applicant_shozoku パラメータを使用して実現してください
カンマ区切りで所属コードを指定（申請可能制限='特定所属のみ'の場合のみ有効）
カンマ区切りでユーザーIDを指定（申請可能制限='特定ユーザーのみ'の場合のみ有効）

リソース設定（修正・削除時の既存データ参照）

第1カラムは必ずresource_idとしてエイリアス指定。
パラメータ: :search_keyword（検索キーワード）, :applicant_user_id（申請者ユーザーCD）, :applicant_shozoku（申請者所属）
例: WHERE owner_shozoku = :applicant_shozoku（所属で制限）/ WHERE owner_user_id = :applicant_user_id（本人のみ）
パラメータ: :resource_id で詳細取得。例: SELECT * FROM ... WHERE user_cd = :resource_id
パラメータ: :resource_id（親リソースID）, :applicant_user_id（申請者ユーザーCD）, :applicant_shozoku（申請者所属）
必須カラム: is_member='Y'(既存メンバー)/'N'(追加可能), is_updatable='Y'(更新可能)/'N'(更新不可)
例: WHERE user_id != :applicant_user_id（申請者自身を除外）
リソースの有効性確認。0行返却でエラー。
